## Metadata differences preserved, not hidden

The unpatched public commit has three documentation entries in `SHA256SUMS`
whose hashes do not match the corresponding current document bytes. In
addition, `verification/imports.json` carries the same stale hash for
`theorem-formal-crosswalk.md`. The first unpatched core attempt failed before
any Lean command with:

```text
PAPER1_CORE_FAIL: source hash mismatch: papers/shifted-square-17-41/theorem-formal-crosswalk.md
```

The required reproduction input [`metadata-hashes.patch`](metadata-hashes.patch)
updates **only five checksum values**: those three documentation entries, the
duplicate stale entry in `imports.json`, and the `SHA256SUMS` checksum of that
revised `imports.json` file. The self-hash update was required by the first
independent recipe run; it is included explicitly rather than suppressed. The
patch leaves all document and source bytes, theorem declarations, proofs and
verifier code untouched. Unmodified
upstream manifests are retained at [`SHA256SUMS.upstream`](SHA256SUMS.upstream)
and [`imports.upstream.json`](imports.upstream.json). The `source_revision`
provenance field in `imports.json` was not rewritten. These are declared
metadata repairs, not a mathematical source patch.

A recipe that omits this patch must retain the preflight failure rather than
reporting the official core runner as passed. For completeness, an earlier
Lake setup command was also launched from an incorrect working directory and
was rerun from the correct source root; that setup error is separate from
both Lean compilation and mathematical verification.

## Scope and non-claims

This closes the practical reproducibility gap for the **selected public-release
checks above**, from named public inputs, with explicit metadata differences.
It does not:

- replay or reproduce the separate historical Lean 4.35 six-checker run;
- certify the historical receipts or later LAB/SPROUT material;
- newly formalise the human Hilbert, maximality or Pell routes;
- formalise the full uniform Hilbert–Jacobi identity;
- add independent external human mathematical review of the manuscript;
- extend the theorem beyond its stated 17/41 domain or establish Erdős 364.

A successful build alone was not used as a substitute for the statement,
axiom, certificate or source-identity checks.
